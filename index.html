1. Introduction

The PMT-5 Fork Head utilizes standard AC kinematics (A-axis rotates about X, C-axis about Z). It is optimized for continuous simultaneous 5-axis aerospace milling. Exclusive Klartext Programming: All toolpaths generated for this machine must strictly use the .H file extension and be output in Heidenhain conversational Klartext. ISO/G-Code is not to be used, as Klartext allows for easier mid-program restarts and console edits.

2. Coordinate Systems (Part vs. Machine)

WARNING ON MOVING TABLE KINEMATICS: The PMT-5 is a moving table machine. The actual physical movement of the machine table (X-axis) will be the opposite of the programmed toolpath direction. Because the table is moving and not the head, an X+ tool move physically shifts the table in the X- direction. Developers: Do NOT flip axis signs in the post-processor. Output standard Cartesian part coordinates and let the Heidenhain kinematic model handle the inversion internally.

Part Coordinate System: All cutting programs default to part coordinates (activated via CYCL DEF 247 PRESETTING or CYCL DEF 7.0 DATUM SHIFT). All XYZ commands are interpreted as absolute positions relative to the active work offset.

Machine Coordinate System: Moves containing M91 ignore all work offsets and move in absolute machine space. Verified highest clearance for tool changes or safe index resets is L Z0 R0 FMAX M91.

3. Tool Length & Radius Compensation

The TNC 640 control automatically applies tool length compensation at all times based on the active tool registry.

Delta Values (Mandatory): The TOOL CALL block should explicitly output DL+0 and optionally DR+0. This explicitly creates a zero-baseline allowing the floor operator to enter wear adjustments directly at the control without hard-coded post overrides.

Radius Compensation: The post-processor must explicitly output the tool radius compensation state on all motion blocks:

  • RL (Radius Left) / RR (Radius Right): Use for standard 2D/2.5D contouring where the control offsets the cutter path.
  • R0 (Tool Center): Required for 3D surfacing, simultaneous 5-axis continuous moves, and safe rapid positioning.

4. Look-Ahead Buffer & Format Constraints

The Heidenhain TNC 640 processes with a 1024-block look-ahead. Use linear Klartext (L) moves for point-to-point motion. Avoid outputting unnecessary non-motion blocks (like redundant M-codes) between tight vectors, as this can flush the buffer and cause the machine to stutter during high-speed surfacing.

Format Constraints:

  • No N-Numbers: Programs must use sequential block numbers (e.g., 1, 2, 3). Do not use ISO N numbers.
  • Single Commands: Commands must be distinct blocks. Do not group distinct operational commands on a single line.
  • Modal Parameters: While coordinates are modal, the post should output all active linear axes (X, Y, Z) and feed rates (F) on every cutting block to ensure absolute safety. Rotary axes (A, C) should only be output during indexing or continuous 5-axis cuts to prevent file bloat.

5. Dynamics (Cycle 32)

To control surface finish and machine acceleration during complex paths, the post must output the complete 3-line Cycle 32 definition.

  • The 1.5x Rule: Tolerance (T) is exactly 1.5 times the CAM Chordal Deviation setting.
  • Angular Tolerance (TA): For continuous 5-axis on the Fork head, TA must be between 1.5 and 2.0 degrees to prevent the rotary axes from stuttering.

Proper Klartext formatting:

CYCL DEF 32.0 TOLERANCE
CYCL DEF 32.1 T0.0015
CYCL DEF 32.2 HSC-MODE:0 TA1.5

6. Program Units, BLK FORM & Probing

CRITICAL UNIT SETUP (INCH VS MM): Heidenhain Klartext requires the unit of measurement to be explicitly declared at the beginning and end of the program (e.g., BEGIN PGM PART INCH). The machine's physical Tool Table must perfectly match this unit base. A mismatch will cause catastrophic dimension scaling.

Header Sizing (BLK FORM): Output a BLK FORM definition at the start of the file to establish the graphical simulator bounding box: BLK FORM 0.1 Z X... Y... Z... and BLK FORM 0.2 X... Y... Z....

Probing Stance: Setup probing utilizes only the Heidenhain supplied canned cycles (TCH PROBE). These are executed manually at the console by the operator. The post-processor should not output automated NC inspection routines.

7. Kinematic Offsets & Limits

To prevent over-travel on large parts, the developer must account for the physical pivot geometry. The PMT-5 Fork Head has a documented Flange Offset of 11.0237 inch (280.0021 mm). This value is handled by the ZinA Transformation within the TNC 640 parameters, mapping the pivot offset distance from the spindle gauge line to the rotational center. Ensure your CAM simulation model reflects this 11.0237" drop to accurately predict Z-axis stroke limits.

8. 3+2 Indexing (6-Step Sequence)

When indexing for 3+2 operations, the post-processor must ensure all A/C axis rotations are non-cutting moves. Use PLANE SPATIAL for all tilted working planes. Do not use standard rotary axis commands (L A... C...) for establishing a work plane. A highly recommended production trick is to assign a Q-parameter to the sequence (e.g., Q5 = -1 and SEQ+Q5) so the operator can toggle the rotary path direction directly at the console.

Strict 6-Step Indexing Sequence:

  1. Retract: Safe clearance along tool axis (M140 MB MAX).
  2. Activate TCPM: Turn on M128 to maintain tool tip positioning safely relative to the part during the rotation.
  3. Rotate & Pre-Position: Output rotary angles with M126 (shortest path), then X/Y/Z.
  4. Deactivate TCPM: Turn off M129.
  5. Lock Plane: PLANE SPATIAL SPA... SPB... SPC... TURN FMAX SEQ+Q5 TABLE ROT
  6. Engage & Cut: Feed to cutting depth.

9. TCPM Simultaneous (M128 & FUNCTION TCPM)

TCPM ensures the control uses the kinematic model to keep the tool tip exactly on the programmed path while rotary axes move. While M128 is the historical standard and perfectly acceptable, the newest Heidenhain TNC 640 standard encourages using FUNCTION TCPM F TCP AXIS POS PATHCTRL AXIS as the modern replacement. Use FUNCTION TCPM if your CAM software natively supports it.

Crucial: Deactivate TCPM (M129 or FUNCTION RESET TCPM) before issuing standard 3+2 indexing commands or M91 home retracts.

10. Feed Control (M116 & FZ)

Standard feed rates are output as F (inch/min or mm/min). For specific high-performance toolpaths, the control also supports FZ (Feed per tooth) if configured in the CAM.

M116 calculates rotary feed rates relative to the tool tip's distance from the pivot center, rather than raw degrees per minute. This is mandatory for all multi-axis paths to prevent severe velocity drops during compound angles.

11. Axis Selection (M138)

Include M138 A C in the program header. This command explicitly defines the physical rotary axes used in the kinematic model, preventing the control from calculating paths for virtual or unequipped axes.

12. Transformations & Arc Formatting

Your post must support Heidenhain coordinate transformations for aerospace part patterning:

  • Cycle 7: Datum Shift (shifting the origin temporarily).
  • Cycle 8: Mirroring (mirroring a toolpath across an axis).
  • Cycle 10: Rotation (rotating the XY plane around the current datum).

Arc Interpolation: When generating circular interpolation, Circle Center (CC X... Y...) coordinates are Absolute by default based on the active datum.

13. Machining Cycles & Klartext Continuations

The post must output standard 200-series cycles using Klartext formatting. Use the tilde (~) character for block continuation. When executing the cycle, use M99 at the exact end of a positioning block (e.g., L X... Y... R0 FMAX M99).

  • Cycle 200 (Drilling):
    CYCL DEF 200 DRILLING ~
    Q200=+0.1 ;SET-UP CLEARANCE ~
    Q201=-1.5 ;DEPTH ~
    Q206=+10 ;FEED RATE ~
    Q202=+0.25 ;PLUNGING DEPTH ~
    Q210=+0 ;DWELL TOP ~
    Q203=+0 ;SURFACE ~
    Q204=+2.0 ;2ND SET-UP
  • Cycle 207 (Rigid Tapping): Imperial pitch is defined as a decimal (e.g., 1/32 pitch = 0.0312).
    Q239=+0.0312 ;PITCH

1. Introduction

The Nutator head on the PMT-5 is specialized for heavy roughing and extreme rigidity. Unlike the Fork head, continuous 5-axis cutting is mechanically restricted due to the complex nutating joint. Post-processors must be built to output discrete 3+2 index angles using .H Klartext format exclusively.

Machine ConfigurationDetails
TypePortal Moving Table (PMT)
Head TypeAC Nutator (Mechanical Pivot)

2. Coordinate Systems

WARNING ON MOVING TABLE KINEMATICS: The PMT-5 is a moving table machine. Programmed X+ motion results in physical X- table movement. Output standard Cartesian part coordinates and let the TNC 640 handle the inversion. Do not reverse axis signs.

Due to the massive, bulky geometry of the Nutator head, M91 machine coordinates and M140 MB MAX are strictly required for safe transitions. Never transition rotary axes while close to the part.

3. Tool Data & Radius Comp

Output DL+0 DR+0 on every TOOL CALL block. This is exceptionally critical for the Nutator, as adjusting tool lengths on tilted planes manually compounds errors rapidly if the post hard-codes the wear offset.

Explicitly output radius comp: RL/RR for contouring, and R0 for rapid/indexing moves.

4. Look-Ahead Buffer & File Format

Maintain standard 1024-block look-ahead. Heavy pocket roughing with the Nutator relies heavily on smooth feed calculation through tight corners. Ensure the post outputs a steady stream of L (Linear) blocks without unnecessary M-code interruptions. Use sequential numbering (no ISO N blocks).

5. Dynamics (Cycle 32)

Use the full 3-line format for Cycle 32. Apply the 1.5x Rule for the T-value based on CAM tolerance. Set Angular Tolerance (TA) to 1.5 degrees. While simultaneous cutting isn't performed, this tolerance setting aids the controller in smoothly accelerating the heavy Nutator head into its indexed positions without jerking the mechanics.

6. Program Units, BLK FORM & Probing

CRITICAL UNIT SETUP (INCH): The machine's physical Tool Table must perfectly match the unit base (INCH/Imperial) of the NC program. Mismatches lead to severe scaling failures during execution. Define BEGIN PGM [NAME] INCH.

Ensure a BLK FORM is output for graphical simulation. Probing utilizes only the supplied canned cycles (TCH PROBE) run manually at the console.

7. Kinematics & Offsets

The Nutator uses Euler mapping (SPA/SPB/SPC) rather than standard A/B/C mapping. The pivot calculation is managed entirely by the TNC controller. The ZinA Transformation maps a Flange offset of 11.0237 inch (280.0021 mm). CAM simulation models must account for this specific offset.

8. 3+2 Indexing

Mandatory: Use PLANE SPATIAL. You MUST use SEQ- to manage the internal cable limits of the Nutator head. This ensures the head takes the safe path to the indexed angle.

Example: PLANE SPATIAL SPA+45.0 SPB+0.0 SPC+90.0 STAY SEQ- TABLE ROT.

9. TCPM Constraints

Do NOT use M128 or FUNCTION TCPM for cutting blocks. It may only be briefly applied during safe air-moves to keep the tool-tip stationary while the head rotates into position, but M129 must be commanded prior to any feed engagement.

10. Feed Control

M116 is mandatory for Nutator indexing transitions. It prevents the machine from rapidly swinging the bulky head at maximum degrees/minute during repositioning. Standard linear feeds use F (in/min).

11. Axis Selection

Define active axes with M138 A C in the header to prevent the TNC from misinterpreting the Nutator geometry or attempting to use virtual axes.

12. Transformations

Cycle 7 (Datum Shift), Cycle 8 (Mirror), and Cycle 10 (Rotation) are fully supported via Klartext and behave identically to standard kinematics. Use Absolute CC X... Y... for arcs.

13. Machining Cycles

Support for Heidenhain 200-series cycles (Cycle 200 Drilling, 207 Tapping). CRITICAL: Ensure Q204 (2nd set-up clearance) is exceptionally large to clear the Nutator's wide sweeping radius during rapid cycle moves. Use the ~ symbol for line continuations and M99 to execute.

1. Introduction

TBM/TBH Gantries equipped with Fork heads are designed for massive continuous 5-axis parts (10m+). They excel in large-scale aerospace and automotive tooling. All outputs must be in conversational .H Klartext format. Ensure standard Right-Hand rule kinematics apply.

2. X-Master/Slave Logic & Coordinates

Program in standard absolute Part Coordinates via CYCL DEF 247. Developers do not need to calculate Gantry leg inertia or split the X-axis signal. The Post outputs standard X values; the Heidenhain controller calculates the real-time parameter adjustments required to keep the X-Master and X-Slave legs perfectly parallel across the floor rail.

3. Tool Data & Radius Comp

Output DL+0 DR+0 on every TOOL CALL. Required for all Tarus platforms to enable shop-floor control of length/radius wear. Must explicitly map RL/RR for contouring or R0 for multi-axis surfacing/rapid moves.

4. Long Travel Buffer & Formatting

Because the Gantry structure is incredibly heavy, smooth point-distribution is essential. The 1024-block look-ahead filter relies on uninterrupted Klartext L blocks to manage acceleration across long distances. Starving the buffer will cause the gantry to judder. Use sequential blocks, no ISO N numbers.

5. Dynamics (Cycle 32)

Use the full 3-line format. CYCL DEF 32.0 TOLERANCE, 32.1 T..., 32.2 HSC-MODE:0 TA1.5. The 1.5x Rule ensures the gantry legs do not attempt to execute abrupt, sharp corners at high speeds, which can induce severe mechanical vibration across the bridge.

6. Program Units, File Format & Probing

CRITICAL UNIT SETUP (INCH): Tool Table units must perfectly match the programmed NC file units (INCH). Failure to align these will cause the machine to interpret tool lengths incorrectly.

Include BLK FORM 0.1/0.2 sizes for simulation. Probing routines use standard Heidenhain TCH PROBE canned cycles, executed manually. Do not output custom NC probing blocks in the post.

7. Safety Retracts (M140 MB MAX)

Crucial for Gantry: M140 MB MAX is the gold standard for retracts. Because the part remains stationary and the entire bridge moves over it, you cannot simply use `Z0 M91` if the head is tilted. The tool must retract along its *own* axis to clear deep cavities before the bridge translates.

8. Gantry Indexing & Q-Parameters

The 6-step indexing sequence is required here as well. Use PLANE SPATIAL ... SEQ+Q5 to allow sequence toggling. Ensure the retract (M140) occurs *before* any rotary axis commands or PLANE commands are issued.

9. TCPM Control (M128 & FUNCTION TCPM)

Use M128 (or the modern FUNCTION TCPM) for simultaneous 5-axis. It perfectly tracks the tool tip even while the massive X-legs traverse the part. Disable with M129 when returning to home or 3-axis indexing.

10. Feed Control

Use M116 for proper rotary velocity control relative to the tool tip. This is especially important given the mass of the Z-axis ram on a gantry. Supports F (inch/min) or FZ (feed per tooth).

11. Axis Selection

M138 A C must be output in the header to confirm active kinematics for the TNC 640.

12. Transformations

Datum shifts (Cycle 7) and Mirroring (Cycle 8) are extremely common on gantries due to the large bed size allowing for multi-part fixturing. Arcs must use Absolute Circle Center (CC).

13. Cycles & Tilted Planes

Standard 200 series cycles apply (Cycle 200, 207) using ~ block continuations and M99. Advanced Tip: If you must execute a standard Z-axis drilling cycle while the physical head is tilted, use PLANE RESET STAY after the physical rotation. This resets the coordinate system to run natively along the new tool vector without physically moving the machine.

1. Introduction

The TBM Gantry equipped with a Nutator head provides extreme rigidity for heavy 3+2 roughing on massive fixed-table parts. Klartext (.H) format is strictly required, and full 5-axis continuous milling is mechanically locked out. Sequential numbering only.

2. X-Master/Slave Logic & Coordinates

Output standard X coordinates via CYCL DEF 247. The controller handles Gantry Leg sync. Because the table is fixed, table inertia is zero, but the sheer mass of the moving gantry bridge and Nutator head requires careful path planning via M91.

3. Tool Data

DL+0 DR+0 is absolutely mandatory on all TOOL CALL blocks to allow manual compensation for the Nutator's angular wear. Maintain R0 for absolute positioning.

4. Look-Ahead Buffer

Maintain standard 1024-block pacing. Minimize block starvation (excessive non-motion blocks) to keep the heavy gantry moving smoothly during deep roughing passes.

5. Dynamics (Cycle 32)

The 1.5x Rule applies strictly to the T value using the full 3-line definition. Set TA to 1.5. Smooth dynamics are critical for accelerating the bulky Nutator head across a gantry rail without causing chatter.

6. Program Units, BLK FORM & Probing

CRITICAL UNIT SETUP (INCH): Tool Table units must perfectly match the programmed NC file units (Imperial/Metric). Establish BLK FORM details in header.

No automated NC probing routines. Use manual TCH PROBE cycles only.

7. Safety Retracts (M140)

Critical combo: Nutator heads on a Gantry must strictly use M140 MB MAX before ANY axis rotation. Due to the fixed table and massive head, the tool must back out of the cavity along its exact tilted vector before the A/C angles change.

8. Nutator Indexing

Use PLANE SPATIAL ... SEQ-. Cable limits must be respected using the SEQ- parameter to prevent the head from "winding up" and hitting mechanical limits.

9. TCPM Constraints

Simultaneous 5-axis is mechanically disabled on this head type. TCPM (M128 or FUNCTION TCPM) is only authorized for safe air-repositioning and must be turned off (M129) before feeding.

10. Feed Control

M116 mandatory for rotary transitions to control head velocity safely.

11. Axis Selection

M138 A C establishes the active Nutator kinematics.

12. Transformations

Cycle 7 Datum Shifts, Cycle 8, and Cycle 10 are fully supported.

13. Cycles

200 Series. Ensure Q204 is exceptionally large to account for the Nutator's pivot geometry during rapid cycle clearing.

1. Introduction

The DHDM (Deep Hole Drilling Machine) specializes in single-lip gundrilling. Posts must integrate extreme Z-depth handling and high-pressure coolant synchronization via Klartext logic (.H format).

2. Coordinate Systems

WARNING ON MOVING TABLE KINEMATICS: The DHDM utilizes a moving table for the X-axis. Programmed X+ motion results in physical X- table movement. Output standard part coordinates; do not manually reverse signs in the post-processor.

Standard part coordinates via Cycle 247. M140 MB MAX is heavily recommended for drill extraction safety before table moves. M91 is used for tool change positions.

3. Tool Data

Output DL+0 DR+0 on TOOL CALL. Essential for tracking drill wear over extremely long bores.

4. Look-Ahead Buffer

While 5-axis surfacing is not the goal, maintain standard Klartext (L) move output structure for X/Y positioning between holes to keep the 1024-block buffer healthy and table transitions smooth.

5. Dynamics (Cycle 32)

Standard Cycle 32 3-line formatting applies. While drilling doesn't require HSC surface finishing tolerances, Cycle 32 maintains smooth table acceleration. T0.01 is generally sufficient.

6. Program Units, File Format & Probing

CRITICAL UNIT SETUP (INCH): Tool Table units must perfectly match the programmed NC file units (INCH). Drill depth scaling errors will lead to severe machine crashes if mixed. Ensure BLK FORM is established.

Probing uses standard TCH PROBE canned cycles operated manually by the machinist.

7. Offsets & Safety

ZinA transformations must account for the specialized gundrill whip-guides and support bushings. Ensure Z retracts (Q204) are set extremely high to clear the pilot hole bushing completely before table motion.

8. Indexing (B-Axis)

If the DHDM is utilizing a rotary table (B-Axis) for compound angle drilling, use PLANE SPATIAL to align the drill vector perpendicularly to the surface before plunging.

9. TCPM Constraints

Simultaneous milling is not the focus; use TCPM (M128) only for safe angular positioning of the table, then disable (M129).

10. Feed Control

Feed control is handled entirely by Cycle 241 parameters during the cut. Rapid positioning moves between holes use FMAX.

11. Axis Selection

Define active rotary axes (e.g., M138 B) if a rotary table is equipped.

12. Transformations

Cycle 7 Datum shifts are frequently used for repeating hole patterns across large mold bases.

13. Cycle 241 (Gundrilling)

Cycle 241 is the mandatory standard for deep-hole gundrilling. It seamlessly handles pilot hole entry, feed ramping, chip breaking, and high-pressure coolant sync automatically. Use the ~ block continuation character and execute with M99.

73 CYCL DEF 241 SINGLE-LIP D.H.DRILL ~
Q200=+0.5 ;SET-UP CLEARANCE ~
Q201=-30.0 ;DEPTH ~
Q202=+3.0 ;PLUNGING DEPTH ~
Q206=+15.0 ;FEED RATE FOR PLUNGING ~
Q211=+0 ;DWELL TIME AT DEPTH ~
Q203=+0 ;SURFACE COORDINATE ~
Q204=+5.0 ;2ND SET-UP CLEARANCE ~
Q379=+0 ;STARTING POINT ~
Q253=+75.0 ;F PRE-POSITIONING

1. Introduction

The UNIMAX is Tarus's universal machining platform. With high agility for mold finishing, post-processors must prioritize Klartext (.H) high-accuracy dynamics and handle extremely point-dense simultaneous outputs without starving the control.

2. Coordinate Systems

Work must be generated in Part coordinates via Cycle 247. M91 is used for absolute machine clearance before tool changes or large 5-axis transitions. Ensure R0 is used for all safe positioning.

3. Tool Data & Radius Comp

DL+0 DR+0 must be output on every TOOL CALL to ensure the operator retains control over tool wear geometry at the console. Use RL/RR for 2D contours and R0 for all 3D/5-Axis moves.

4. Look-Ahead Buffer

Look-ahead is extremely critical for UNIMAX surfacing. The 1024-block buffer must be fed a continuous stream of Klartext L blocks. Avoid frequent M-code pauses that break the buffer chain and cause facets on the mold.

5. Dynamics (Cycle 32)

Apply the full 3-line 1.5x rule. For fine finishing passes on the UNIMAX, tolerances may go as tight as T0.0002, meaning Cycle 32 must be output with extreme precision. Set TA (Angular Tolerance) to match the CAM model to prevent rotary jerking.

6. Program Units, Formats & Probing

CRITICAL UNIT SETUP (INCH): Tool Table units must perfectly match the programmed NC file units (INCH) to avoid catastrophic layout errors. Ensure BLK FORM sizes are established.

Probing relies on standard Heidenhain TCH PROBE cycles run manually.

7. Offsets & ZinA

Refer to specific UNIMAX head geometry parameters supplied at install. The ZinA transformation maps the pivot offset to ensure TCPM accuracy across all angles.

8. Indexing

PLANE SPATIAL sequence is identical to standard Tarus setups (Retract via M140 → M126 → PLANE SPATIAL). Do not output rotary vectors manually to index.

9. TCPM (M128 & FUNCTION TCPM)

Full M128 (or modern FUNCTION TCPM) support is required for 5-axis surfacing. Disable with M129 when returning to 3-axis indexing or home.

10. Feed Control

M116 is mandatory for rotary feed calculation to ensure feed is calculated at the tool tip. High-performance paths may utilize FZ (Feed per tooth).

11. Axis Selection

M138 required based on the specific head style equipped (e.g., M138 A C or M138 B C).

12. Transformations

Cycle 7 (Datum Shift), Cycle 8 (Mirror), and Cycle 10 (Rotation) fully supported.

13. Cycles

Standard 200-series applies (Cycle 200 Drill, Cycle 207 Tap). Ensure Setup Clearance (Q200) and Depth (Q201) are explicitly defined using Klartext ~ continuations. Arcs must use Absolute Circle Center (CC X... Y...).
